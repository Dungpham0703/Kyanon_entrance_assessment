# Kyanon Entrance Assessment

This repository contains my solution to the Kyanon entrance assessment.

## Prerequisites
Ensure you have the following installed:
- Python 3.x
- Required libraries:
    - `pandas`
## Installation
  Clone the repository:
    ```
    git clone https://github.com/Dungpham0703/Kyanon_entrance_assessment.git
    ```
## Usage
To run the pipeline:
    Run the script:
        ```
        python -m src.main.py
        ```
        and you will see the report.csv in data folder. Thank you for visiting!
